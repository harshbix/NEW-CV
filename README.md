# Interactive Resume - Rose John Mosha

This project is a print-layout HTML resume designed to look like a standard A4 document.

## Features

- **Print-Ready Layout:** CSS configured for A4 dimensions (210mm x 297mm).
- **Design System:** Uses CSS variables for consistent theming.
- **Typography:** Integrated Google Fonts (Montserrat and Open Sans).
- **Icons:** Font Awesome 6.4.0 integration.

## Structure

- `index.html`: Main HTML structure.
- `style.css`: Styling and layout logic.
